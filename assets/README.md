# OpenSci Icon

The open O stands for open science and continuing exploration. Its separate point represents a new discovery and independently verifiable evidence. Blue and green connect rigor, knowledge and growth. The mark keeps a clear silhouette at small sizes.

The project-root `OpenSci.lnk` uses this icon and opens `Start-OpenSci.cmd`. Machine-specific shortcuts and local configuration are outside the source delivery manifest; recreate them for the actual installation path after migration.
- `opensci-icon.svg`: Editable vector source.
- `opensci-icon.png`: 512 × 512 preview.
- `opensci.ico`: Windows icon with 16, 24, 32, 48, 64, 128 and 256 pixel images.
