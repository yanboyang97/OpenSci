# Manuscript outputs
Use Word + Zotero or Quarto/LaTeX + an explicitly exported references.bib.
Every figure/table must link to an experiment ID and source data.
The AI disclosure statement must follow the target venue's current policy.

Native Word tasks preserve a saved-version recovery copy and use the observed Zotero plugin; the verifier never generates citation fields. Keep existing manuscripts and keys intact and validate in copies. LaTeX/Quarto exports preserve a manuscript-specific key map and require actual compilation.
